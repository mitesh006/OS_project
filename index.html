HOW TO PLAY

🎮 Core Gameplay

Each level pits you against a CPU Scheduling Algorithm Boss. The boss uses a specific scheduling algorithm to decide which process gets the CPU.

Your job: Predict the correct scheduling decision before the timer runs out!

⚔️ Combat

  • Correct Answer → Boss loses HP + Score + Combo
  • Wrong Answer → You lose HP + Combo resets
  • Fast Answer → Bonus damage!
  • Timer Expires → Boss attacks!

📊 Scheduling Algorithms

  • FCFS — First arrival gets CPU first
  • SJF — Shortest burst time goes first
  • Priority — Lowest priority number goes first
  • Round Robin — Each process gets a time quantum
  • SRTF — Preemptive: shortest remaining time wins

🏆 Scoring & Ranks

  • S Rank: 95%+ accuracy, low damage taken, no hints
  • A Rank: 80%+ accuracy
  • B Rank: 65%+ accuracy
  • C Rank: 50%+ accuracy
  • D Rank: Below 50%
